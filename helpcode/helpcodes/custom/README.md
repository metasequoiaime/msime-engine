# 自定义辅助码

把自己的辅助码方案放进本目录，就能在使用引擎的设置页里选择它。修改正在使用的方案文件后，切换一次方案或重启输入法才会重新加载。

## 文件格式

- 文件扩展名必须是 `.txt`，编码使用 UTF-8，可带 BOM。
- 每行一个字：`字=辅助码`。引擎取等号后的前两个小写英文字母，例如 `妈=nm`。
- 以 `#` 开头的行是注释，会被忽略；文件可以使用 LF 或 CRLF 换行。
- 方案名为 `custom/<文件名去掉 .txt>`。文件名只能是一个文件名，不能包含路径分隔符。

## 显示名称

默认使用文件名显示方案。想提供中英文名称，可以在第一个词条前写注释：

```text
# name: 我的辅助码
# name_en: My Helpcode
阿=ek
锕=jk
```

冒号可以使用半角 `:` 或全角 `：`。只写一个名称时，设置页可用同一个名称作为另一种语言的后备值。
